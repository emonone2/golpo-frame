## 🌟 পরিচিতি (About GolpoFrame)

**গল্পফ্রেম (GolpoFrame)** হলো একটি আধুনিক ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন যা ব্যবহারকারীদের ব্যক্তিগত ডায়েরি, দৈনন্দিন অভিজ্ঞতা বা গল্পকে সুন্দর কমিক বা কার্টুন স্ট্রিপে রূপান্তর করতে সাহায্য করে।

- **জিরো-বাজেট প্রসিডিউরাল কার্টুন ইঞ্জিন:** পেইড এআই এপিআই ছাড়াও সরাসরি উচ্চমানের ভেক্টর কার্টুন আর্টওয়ার্ক জেনারেট করে।
- **অথেন্টিক বাংলাদেশি কমিক স্টাইল:** Basic Ali / Unmad / Dhaka Comics এর আদলে খাঁটি বাংলাদেশি চরিত্র ও দৃশ্যপট।
- **স্মার্ট কমিক স্টুডিও:** প্রতিটি প্যানেল, ডায়লগ বাবল, ক্যাপশন, সাউন্ড এফেক্টস (SFX) ও চরিত্র পরিবর্তনের পূর্ণ নিয়ন্ত্রণ।
- **সোশ্যাল গ্যালারি ও কমিক রিডার:** তৈরি করা কমিক শেয়ারিং, বুকমার্ক, ফুলস্ক্রিন রিডার ও লাইক সুবিধা।
- **মাল্টি-ফরম্যাট এক্সপোর্ট:** কমিক স্ট্রিপ ও প্রতিটি প্যানেল হাই-রেজোলিউশন PNG ও SVG ফরম্যাটে তাৎক্ষণিক ডাউনলোড।

## 🎭 চরিত্রসমূহ (Authentic Bangladeshi Presets)

1. **রাফি (নায়ক)** - ডেনিম জ্যাকেট, স্পোর্টস ওয়াচ ও স্পাইকি হেয়ারসহ প্রাণবন্ত তরুণ নায়ক।
2. **নুসরাত (চশমা পরা আপু)** - কুর্তি ও ওড়না, স্টাইলিশ রাউন্ড চশমা, ঝুমকা ও স্টাডি বুকসহ আপু।
3. **তামিম (বন্ধু)** - হুডি, গলায় বড় ডিজে হেডফোন, স্মার্টফোন ও ফ্রেন্ডলি দাড়িওয়ালা বেস্ট ফ্রেন্ড।
4. **শিক্ষক (করিম স্যার)** - ফরমাল শার্টের পকেটে লাল-নীল কলম, সাইড-পার্টেড পাকা চুল ও চশমা পরা মাস্টার স্যার।
5. **খালা** - লাল সুতি শাড়িতে সোনালী জড়ির পাড়, কোমরে ঐতিহ্যবাহী পিতলের চাবির গোছা ও কপালে লাল টিপ।
6. **দারোয়ান কাকু** - খাকি ইউনিফর্ম, স্টার শিল্ড ব্যাজ, অফিসিয়াল পিকড ক্যাপ, বাঁশি ও বাঁশের লাঠি।
7. **রিকশাওয়ালা মামা** - মাথায় বাঁধা লাল-সাদা চেক গামছা, চেক লুঙ্গি ও রিকশা হর্নসহ মামা।
8. **টংয়ের চা মামা** - বিস্ট্রো অ্যাপ্রন, কাঁধে নীল তোয়ালে ও হাতে খাঁটি ধোঁয়া ওঠা মালাই চায়ের কাঁচের গ্লাস।
9. **অনন্যা (মেধাবী ছাত্রী)** - এলিগেন্ট হিজাব, ফুল ব্রোচ পিন, চশমা ও বুকে জড়িয়ে রাখা পাঠ্যবই।
10. **ফাহিম (ক্যাম্পাসের গায়ক)** - পিঠে অ্যাকোস্টিক গিটার, লাল রকার ব্যান্ডানা ও বোহেমিয়ান ডেনিম ভেস্ট।
11. **ট্রাফিক পুলিশ** - আকাশী নীল শার্ট, নেভি ব্লু বেরেট ক্যাপ, রিফ্লেক্টিভ স্যাশ ও সাদা ট্রাফিক গ্লাভস।
12. **দাদী / খালাম্মা** - লাল পাড় সাদা সুতি শাড়ি, চেইন দেওয়া রিডিং চশমা, রূপালী খোঁপা ও কাঠের তাসবিহ।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Lucide React
- **Backend & Auth:** Supabase (Auth, PostgreSQL DB, Row Level Security, Edge Functions)
- **Vector Rendering:** Procedural SVG engine with cel-shading & dynamic gradients
- **Testing:** Node.js native test runner with `tsx` (10/10 tests passing)

## 🚀 লোকাল সেটআপ (Getting Started)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/emonone2/golpo-frame.git
cd golpo-frame
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভ্যারিয়েবল সেট করুন:
`.env.example` ফাইলটি কপি করে `.env` তৈরি করুন:
```bash
cp .env.example .env
```
প্রয়োজন অনুযায়ী আপনার Supabase URL ও Anon Key বসিয়ে নিন।

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:5173/`

### ৫. টেস্ট ও প্রোডাকশন বিল্ড:
```bash
npm test        # টেস্ট রান করতে
npm run build   # প্রোডাকশন বিল্ড তৈরি করতে
```
